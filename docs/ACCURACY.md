# 정확도 검증 (Phase 0 게이트)

> 상태: **미실행.** 실데이터 그래프가 생기면 엔진 값을 채우고, 지도 앱 값은 사용자가 직접 확인해 입력한다(Claude는 지도 앱을 조회하지 않는다).
> 통과 기준: 평균 절대 오차 ≤ 5분. 넘으면 구현을 멈추고 범위 축소안(예: 서울 1~9호선 한정)을 제시한다.

## 입력 방법
- 지도 앱: 평일 오후 2시 출발 기준, "지하철만" 옵션, 첫 번째 추천 경로의 **탑승~하차 시간**(도보 이동 제외)과 환승 수.
- 엔진 값: `npm run data:build` 후 테스트 스크립트로 계산(Phase 0에서 추가).
