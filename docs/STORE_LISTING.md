## 상세 설명 (초안)
```
사잇 - 우리 사이를 잇다

2~6명이 각자 출발역을 넣으면, 가장 오래 걸리는 사람의 시간이 가장 짧은 지하철역을 추천해요.
모두의 소요시간과 환승 횟수를 나란히 보여 주니까 누가 손해 보는지 따질 필요 없이 바로 정할 수 있어요.

· 출발역 검색: 역 이름 일부나 초성(ㄱㄴ)으로 찾기
· 추천 결과: 가장 오래 걸리는 사람 기준 공평한 역 + 다른 후보 5곳
· 상세 경로: 사람마다 노선·환승·예상 시간
· 링크 공유: 로그인 없이 링크 하나로 결과 공유

수도권 지하철·광역철도 21개 노선을 지원해요. 시간은 공공데이터(서울교통공사 운행시간, 국토교통부 시간표) 기준 추정치이며 실제와 다를 수 있어요.
```
(노선 수는 `app/src/data/graph.v1.json`의 lines 기준 — 2026-10-30 현재 21개. 노선을 더하면 고친다.)
