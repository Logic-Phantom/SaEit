## 다시 받기
```bash
npm run data:fetch
```
포털 다운로드 한도에 걸려 보안문자를 요구하면 스크립트가 멈춘다(우회하지 않음). 그때는 브라우저에서 직접 받아 같은 파일명으로 `data-build/raw/`에 둔다.
