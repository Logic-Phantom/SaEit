## 적용 절차
1. 원본을 `data-build/raw/`에 기준일 포함 파일명으로 저장(수정 금지).
2. `data-build/src/sources/<소스>.ts` 어댑터가 원본 → `RawDataset`(노선·구간·환승·출처)으로 변환. 컬럼명은 실제 파일을 보고 정한다(추측 금지).
3. `build-graph.ts`의 입력을 데모 어댑터에서 실데이터 어댑터로 교체 → `npm run data:build` → `docs/COVERAGE.md` 확인.
4. 역명 정규화 규칙(`normalize-station.ts`)에 원본별 예외·동명이역 매핑 추가.
