# 앱인토스 비게임 체크리스트 대응

출처: https://developers-apps-in-toss.toss.im/checklist/app-nongame.md (2026-10-30 확인). 상태: `구현` / `샌드박스 확인` / `토스앱 확인` / `해당 없음`.

| 항목 | 대응 | 상태 |
|---|---|---|
| 토스 내비게이션 바 사용, 자체 로고 금지 | `navigationBar: { withBackButton, withHomeButton }`, 화면 헤더에 큰 로고 반복 없음 | 구현 |
| 토스 뒤로가기와 미니앱 뒤로가기 동시 노출 금지 | 토스 안에서는 자체 뒤로가기 숨김(D-005) | 구현 (토스앱 미확인) |
| 첫 화면에서 뒤로가기 시 종료, Android 뒤로가기 동작 | 해시 히스토리 사용, 첫 화면에 추가 히스토리 없음 | 구현 (토스앱 미확인) |
| 스킴 진입 후 뒤로가기 | 진입 리다이렉트는 `replace` | 구현 (토스앱 미확인) |
| CSR/SSG만, eval·외부 코드 실행 금지, iframe 금지 | Vite CSR, eval·iframe 없음 | 구현 |
| 타 도메인 이동·렌더링 금지 | 외부 링크 없음 | 구현 |
| HTTPS만 | 런타임 네트워크 요청 없음(그래프 번들 포함) | 구현 |
| 라이트 모드만 | `color-scheme: light`, 다크 테마 없음 | 구현 |
| 핀치줌 비활성 | viewport `maximum-scale=1, user-scalable=no` | 구현 |
| 2초 이상 지연 금지 | 6명 × 데모 그래프 계산 < 200ms(자동 테스트 상한), 실기기 미측정 | 구현 |
| 진입 즉시 바텀시트 금지 | 진입 시 모달·권한 요청 없음 | 구현 |
| 공유 링크는 `intoss://` | `Share.createLink({ path: 'intoss://saeit/result?…' })` | 구현 (샌드박스 미확인) |
| SDK 브리지 과다 호출 금지 | 저장은 사용자 행동 시에만, 루프·타이머 호출 없음 | 구현 |
| 사용 기록 유지(재진입 후) | 토스 Storage에 기록·최근 역 저장 | 구현 (토스앱 미확인) |
| 권한 거부 시에도 동작 | 클립보드 권한만 사용, 실패 시 토스트 안내 후 공유 시트 사용 가능 | 구현 (토스앱 미확인) |
| 위치·알림 권한 | 사용 안 함 | 해당 없음 |
| 토스 로그인·인앱결제·토스페이 | 사용 안 함 | 해당 없음 |
| 인앱 광고 | Phase 4 | 미착수 |
| 국문 앱 이름 = 콘솔 등록명, 오인 표현 금지 | "사잇"(콘솔 미등록). '토스'·운영기관명 미사용 | 사용자 확인 필요 |
